# 👾 DIGI-FEED (디지몬 자동 서칭 & 모니터링 앱)

디지몬 관련 최신 뉴스, 피규어/굿즈 발매 정보, 디지카(카드게임), 커뮤니티 인기글 및 공식 디지몬 도감 기준 도감을 PC와 스마트폰(PWA)에서 한눈에 모아보는 실시간 모니터링 앱입니다.

## 🌟 주요 특징

1. **서버 비용 & 관리 부담 0원 (Serverless)**
   - 24시간 켜둘 서버가 필요 없이 **GitHub Actions**가 주기적으로 자동 수집.
   - 외부 유료/무료 DB 회원가입 없이 **GitHub 자체 저장소(Flat JSON)**로 관리.
2. **PC & 모바일 완벽 지원 (PWA)**
   - PC에서는 와이드 3열 그리드로 시원하게 탐색.
   - 스마트폰에서는 브라우저의 **"홈 화면에 추가"**를 누르면 앱스토어 설치 없이 실제 앱처럼 동작.
3. **취향 맞춤 필터 & 스크랩**
   - 카테고리 필터: `전체`, `🧸 피규어/굿즈`, `🃏 카드게임(TCG)`, `🎮 게임/애니`, `🔥 커뮤니티 인기글`
   - 실시간 키워드 검색
   - 즐겨찾기(스크랩) 기능 (브라우저 로컬 저장)
   - 다크 모드 / 라이트 모드 지원
4. **공식 디지몬 도감 기준 도감**
   - 공식 도감 번호·기본 정보 + 공식 페이지 연결, 공식 "관련된 디지몬" 기반 진화. 구조는 [DEX.md](DEX.md) 참고.

## 🚀 빠른 시작 (로컬 실행)

### 1. 데이터 수집 실행
```bash
cd scraper
pip install -r requirements.txt
python crawl.py
```
실행이 완료되면 `docs/digimon_feeds.json`에 최신 소식이 자동으로 수집/저장됩니다.

### 2. 웹앱 실행
```bash
# docs 디렉토리에서 간단한 웹서버 구동
cd docs
python -m http.server 8080
```
브라우저에서 `http://localhost:8080`에 접속하면 완성된 앱을 바로 사용할 수 있습니다.

---

### 3. 테스트
```bash
python -m unittest discover -s tests
```

## 🧩 수집 소스 추가하기

1. `scraper/crawl.py` 에 `make_item(...)` 목록을 돌려주는 크롤러 함수를 만듭니다. 오류는 `log_error(...)` 로 남기면 수집 상태에 집계됩니다.
   - 구글 뉴스 `site:` 검색이면 `_crawl_site_search([...])` 한 줄로 충분합니다.
2. 같은 파일의 `SOURCES` 목록에 `("소스 이름", 함수)` 한 줄을 추가합니다.

모든 소스는 동시에 수집되며(`CRAWL_WORKERS`, 기본 6), 일시 오류(429·5xx)는 자동 재시도합니다.
소스별 결과(건수·오류)는 `digimon_feeds.json` 의 `sources` 에 기록되고, GitHub Actions 실행 화면에는 0건인 소스가 경고로 표시됩니다.

## 📱 스마트폰에서 '앱'으로 사용하는 방법 (PWA)
- **아이폰 (Safari)**: 하단 공유 버튼(`공유 아이콘`) -> **'홈 화면에 추가'**
- **갤럭시/안드로이드 (Chrome)**: 우측 상단 메뉴(`⋮`) -> **'홈 화면에 추가'** 또는 앱 화면 하단의 '추가' 배너 클릭
- 홈 화면에 주황색 디지몬 아이콘이 생기며, 주소창 없는 깔끔한 전체화면 앱으로 쾌적하게 실행됩니다.
